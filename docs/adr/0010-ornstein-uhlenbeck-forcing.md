# Forcing is an exact, reproducible Ornstein-Uhlenbeck process

Forcing evolves the coefficients of the modes with $0 < |\kappa| \le \kappa_f$ by the exact update $a \leftarrow a e^{-\Delta t / \tau} + \sigma \sqrt{1 - e^{-2 \Delta t / \tau}} \, \xi$, with $\xi$ unit Gaussian noise and $\sigma$ the steady standard deviation of a coefficient, so that its statistics do not depend on the time step, which the CFL controller varies. The amplitude is the rms of the steady force, shared equally by the forced modes and the directions normal to each wavenumber, and the noise is solenoidal when drawn, so the projection removes none of it. The coefficients, the forcing's history, start from a draw of the steady distribution rather than from zero, and the noise comes from a seeded CPU generator whose state is, with them, the term state: the forcing is then the same bit for bit on CPU and GPU and on every rank, and a resumed run reproduces the uninterrupted one. Alvelius forcing was rejected: it chooses its phases so that the force does no work on the current velocity, so its injection, a time-discretization effect proportional to the time step, cannot be seen in the budget spectra.
