# Periodic in every direction, permanently

Specflow only solves problems that are periodic in every direction. Every field therefore has a Fourier representation, every derivative and every linear operator is a multiplier per wavenumber, and every transform is an FFT; the core relies on this throughout. Wall-bounded flows, which need non-periodic directions (Chebyshev, Legendre), belong in a separate code rather than behind an abstraction here.
